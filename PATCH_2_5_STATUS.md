# Патч 2.5 — состояние проекта

Исходный архив патча 2.5 пока не загружен. Для установки Android требуется загрузить все файлы Android-проекта с сохранением путей, затем собрать и проверить APK.

Реализованы в архиве: обновлённая тёмно-синяя и золотая палитра, карточки трёх домов, локальные функции справочника и упрощённого конструктора.

Не реализованы полностью: настоящий GPT-помощник через API, синхронизация Android/iOS, права пользователей, полный согласованный редизайн. APK не собран.
