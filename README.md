# Управление домами — версия 2.5

Android-приложение для управления объектами «Ярославка», «Монолит» и «Баня». Разработка iOS-версии должна использовать те же бизнес-правила и общую серверную модель.

## Статус на GitHub
Сейчас добавлены инструкция импорта, список требований и workflow сборки. **Сам исходный Android-проект из архива 2.5 нужно загрузить отдельно с сохранением вложенных папок.** Инструкция: [IMPORT_2_5.md](IMPORT_2_5.md).

## Состав патча
- Локальный WebView Android (Java + HTML/JS), задачи и календарь.
- Тёмно-синие и золотые элементы интерфейса, фото-карточки домов.
- Локальный справочник сотрудников и приглашённых специалистов с поиском.
- Локальный упрощённый конструктор разделов.
- Прототип экрана помощника (не полноценный GPT).

## Ещё не готово
- Подключение OpenAI API и полноценные голосовые/текстовые действия.
- Серверная база и синхронизация Android/iPhone.
- Система авторизации, прав пользователей и аудит.
- Полная реализация всех утверждённых дизайн-макетов.
- Установочный APK (до успешной сборки Actions).
