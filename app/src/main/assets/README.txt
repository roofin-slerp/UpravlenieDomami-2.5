УПРАВЛЕНИЕ ДОМАМИ — тестовая версия 2.2 (PWA)

Это устанавливаемое веб-приложение для Android, НЕ APK.

Как установить на Android:
1. Разместите все файлы папки на HTTPS-хостинге, сохранив структуру (например, GitHub Pages, Netlify или Cloudflare Pages).
2. Откройте полученную HTTPS-ссылку в Google Chrome на Android.
3. Откройте меню Chrome (три точки) -> «Установить приложение» или «Добавить на главный экран».
4. Откройте значок «Дома» на телефоне.

Локальная проверка на компьютере: в папке выполните python -m http.server 8000 и откройте http://localhost:8000.

ВАЖНО:
- Вход по номеру и паролю — демонстрационный. Любые введённые данные подходят, реальной аутентификации и защиты финансов нет.
- Все данные хранятся локально в браузере конкретного устройства (localStorage).
- Чат не передаёт сообщения другим людям.
- Push-уведомления, фото/видео и синхронизация не реализованы.
- Перед очисткой данных браузера создайте резервную копию в разделе «Ещё» -> «Резервная копия».
- Не вводите реальные конфиденциальные сведения, номера телефонов и пароли в тестовую версию.
