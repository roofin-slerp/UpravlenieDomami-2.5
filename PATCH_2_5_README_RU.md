# Патч 2.5 — техническое описание и статус

## Согласованный дизайн
Тёмно-синий фон, золотые акценты, подтверждённые карточки трёх домов «Ярославка», «Монолит», «Баня». Экран приложения: карточки объектов, задачи, календарь, сотрудники, приглашённые специалисты, расходы, отчёты, нижняя панель с помощником. Экран объекта: обслуживание, инженерные системы, уборка, сад, техника, расходы, документы, фото/видео, журнал работ. Не менять утверждённые изображения без отдельного согласования.

## Люди и контакты
Единый справочник: один человек — одна карточка; сотрудники и приглашённые специалисты, ФИО, должность/специальность, телефон, WhatsApp/Telegram/email, фото, объекты, статус, задачи, история работ и оплат. Поиск по имени, должности, телефону и обслуживаемому объекту. Редактирование фото в Android/iOS с камеры или галереи.

## GPT-помощник (требует разработки)
Администраторы Олег и Виталия могут задавать текстовые и голосовые команды, запрашивать контакты, создавать и менять задачи, встречи, расходы и разделы, запрашивать отчёты. Перед изменениями — предварительный просмотр и подтверждение; особенно строго для финансов, удаления, прав доступа. Логировать автора каждой операции. API-ключ OpenAI нельзя хранить в мобильном приложении.

## Разделы и конструктор
Создание и редактирование общих и объектных разделов и вложенных подразделов, наборы полей (текст, дата, деньги, задача, фото, файл), порядок, архив, права, история. Команды помощнику на создание разделов, сохранять только после подтверждения.

## Данные и безопасность
Единая серверная база и API для Android/iPhone, отдельные учётные записи, роли, права доступа для сотрудников, история изменений, резервные копии. Локальный WebView-прототип не обеспечивает безопасную многопользовательскую работу.

## Реальное состояние архива 2.5
- Включён Android WebView-проект на Java, HTML, JS, Gradle.
- Включена частичная тёмно-синяя/золотая тема и изображения объектов.
- Включены локальные задачи, календарь, расходы, контакты, упрощённый конструктор.
- Включён локальный прототип помощника и попытка голосовой диктовки при поддержке браузерного движка.
- **НЕ включены** полноценный GPT по API, серверная синхронизация, полноценная авторизация и точный редизайн всех внутренних экранов.
- APK ещё не собран и не протестирован.
